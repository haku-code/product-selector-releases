# 製品選定 macOS

macOS 14以上、Apple Silicon／Intelに対応した製品・見積管理アプリです。

[最新版をダウンロード](https://github.com/haku-code/product-selector-releases/releases/latest)し、ZIPを展開してProductSelector.appをアプリケーションフォルダへ配置してください。

配布アプリはDeveloper ID署名・Apple公証済みです。データはアプリ本体の外に保存され、更新時にも保持されます。

1.0.2以降はアプリメニューの「アップデートを確認…」と設定画面の自動更新設定を利用できます。1.0.1からの初回移行は手動で入れ替えてください。

このリポジトリには配布物と署名付き更新情報のみを公開します。appcast.xmlは署名済みのため、手動編集しないでください。
